🔌 APIs EXTERNES (à utiliser dans les phases suivantes)
-------------------------------------------------------------------
PHASE 1 (Macro):
  Fred API (Reserve Federale, gratuit, illimite)
    - Inscription:       https://fredaccount.stlouisfed.org/apikey
    - Documentation:     https://fred.stlouisfed.org/docs/api/fred/
    - Series catalogue:  https://fred.stlouisfed.org/categories
    - Python wrapper:    https://github.com/mortada/fredapi

PHASE 2 (Company):
  Finnhub (donnees societes, gratuit 60 calls/min)
    - Inscription:       https://finnhub.io/register
    - Documentation:     https://finnhub.io/docs/api
    - Python wrapper:    https://github.com/Finnhub-Stock-API/finnhub-python

  Yahoo Finance (gratuit, sans cle)
    - Python wrapper:    https://github.com/ranaroussi/yfinance

  SEC Edgar (filings, gratuit)
    - Documentation:     https://www.sec.gov/edgar/sec-api-documentation
    - Python wrapper:    https://github.com/jadchaar/sec-api

PHASE 3+ (News & autres):
  NewsAPI (gratuit 100 calls/jour)
    - Inscription:       https://newsapi.org/register
    - Documentation:     https://newsapi.org/docs
